01 · COMPS

Comparable multiple

For each category, take the median log market-cap / TVL ratio among snapshot protocols with a positive recorded market cap. Shrink the category estimate toward the snapshot-wide median with four prior peers. Sparse categories lean more on the global baseline.

02 · MOMENTUM

Seven-day signal

Use the snapshot’s 7D TVL change through a bounded, smooth factor. The input is clipped to −50% / +100% before adjustment so a short noisy window cannot dominate the estimate. Missing change is neutral.

03 · OBSERVATION

Tracking tenure

Older observed histories receive a modest maturity adjustment that saturates. This is only time tracked by DefiLlama, not the protocol’s true start date; missing dates use a neutral fallback.

LIMITS / READ BEFORE YOU FARM

No token, reward or timing claim.

The snapshot says what one source records as of its fetch time. It does not establish token issuance, airdrop eligibility, safety, sustainability or current contract state. Values are comparison scenarios—not financial advice or an expected payout.
